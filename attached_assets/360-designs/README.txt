360° Pool Design Images
=======================

Place your exported 360° panoramic JPG images from Structure Studios/Vip3D here.

File naming convention:
- Use descriptive names: modern-luxury-pool.jpg, tropical-paradise.jpg, etc.
- Supported formats: JPG, PNG
- Recommended resolution: 4096x2048 or higher for best quality

To add a new 360° design:
1. Export 360° panoramic image from Structure Studios/Vip3D
2. Place the JPG file in this folder
3. Update the design list in virtual-reality.tsx with the filename
4. The viewer will automatically load your new design

Example files:
- sample-pool-360.jpg (sample 360° image - replace with your designs)
